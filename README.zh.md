## 游戏制作工具

**[像素素材工坊](https://github.com/daetz-coder/pixel-asset-workshop)** 可以把同一段动画视频拆成多个角色的游戏精灵图。内置的 **SpriteFrame 逐帧工作台**在本机运行，可裁切、抠像、挑帧和排序，并导出透明 PNG、精灵图集和 GIF。项目提供 Godot 实机对照，以及六套可按 CC0 复用的精灵素材。

[观看 Godot 演示](https://daetz-coder.github.io/projects/pixel-asset-workshop/showcase/godot.html) · [下载 SpriteFrame（ZIP）](https://github.com/daetz-coder/pixel-asset-workshop/archive/refs/heads/main.zip) · [中文安装教程](https://daetz-coder.github.io/projects/pixel-asset-workshop/showcase/spriteframe.zh.html#install)
